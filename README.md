Palmera Nights — an original open-world crime game that runs entirely in the browser. Explore the 5×5-block city of Palmera on foot or by car, run Rosa Delgado's mission chain (timed delivery, hot package, repo job), dodge a 1–5 star police response, fight with fists or a pistol, and save your progress locally. Built with vendored Three.js; zero network requests.

## Run it

```sh
npx serve game
# then open the printed URL (game/index.html)
```
